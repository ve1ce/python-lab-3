# Лабораторная работа №3

## Приложение для изучения иностранных языков

Настольное приложение на Python для изучения английских слов, выполнения упражнений и отслеживания активности пользователя.

Проект разработан в рамках лабораторной работы №3 «Работа с графическим интерфейсом на Python».

**Выполнены уровни Rare, Medium и Well-done.**

Веб-версия использует FastAPI, Uvicorn и шаблоны Jinja2. База данных PostgreSQL 17 разворачивается в Docker Compose.

## Описание

Приложение предоставляет графический интерфейс для работы с персональным словарём и прохождения тренировок на перевод английских слов.

Интерфейс реализован с использованием библиотеки PySide6. Для построения графиков активности используется Matplotlib.

Программа построена с применением объектно-ориентированного программирования.

## Возможности настольной версии

### Главная страница

- Отображение количества слов в словаре.
- Отображение количества завершённых тренировок.
- Подсчёт дней активности.
- График активности за последние семь дней.
- Просмотр последних действий пользователя.

### Словарь

- Просмотр таблицы английских слов и переводов.
- Добавление новых слов.
- Удаление выбранных записей.
- Поиск по английским словам и русским переводам.
- Проверка корректности введённых данных.

### Практика

- Тренировка перевода английских слов.
- Случайная выборка вопросов из словаря.
- Четыре варианта ответа.
- Проверка правильности ответа.
- Отображение прогресса тренировки.
- Подсчёт правильных ответов.

### История

- Автоматическая регистрация действий пользователя.
- Фиксация добавления и удаления слов.
- Сохранение результатов тренировок в SQLite между запусками.
- Отображение даты, времени и описания событий.

## Установка и запуск настольной версии

Для запуска приложения необходим Python и совместимые версии используемых библиотек.

### 1. Получение проекта

Склонируйте репозиторий с GitHub или скачайте архив проекта.

Перейдите в корневую директорию `python-lab-3`.

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация виртуального окружения

В Windows (PowerShell) выполните следующую команду.

```powershell
.\.venv\Scripts\Activate.ps1
```

В Linux и macOS выполните следующую команду.

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 5. Запуск приложения

```bash
python main.py
```

## Запуск веб-версии

1. Установите Docker с плагином Docker Compose и запустите Docker Desktop или Docker Engine.
2. Создайте `.env` в корне проекта. Подставьте свой локальный пароль вместо примера. При использовании уже инициализированного тома укажите пароль, заданный при его создании.

   ```dotenv
   POSTGRES_PASSWORD=your_local_password
   ```

3. Поднимите PostgreSQL и проверьте состояние контейнера.

   ```bash
   docker compose up -d db
   docker compose ps
   docker compose exec db pg_isready -U lab_user -d language_lab
   ```

   PostgreSQL доступен на `127.0.0.1:5433`. База `language_lab` использует пользователя `lab_user`. Данные сохраняются в томе `postgres_data`.

4. После готовности PostgreSQL запустите FastAPI.

   ```bash
   python -m uvicorn web.main:app --reload
   ```

   Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000). При запуске приложение создаёт недостающие таблицы, а при первом создании словаря добавляет восемь начальных слов.

5. Для остановки нажмите Ctrl+C в терминале Uvicorn и выполните `docker compose stop db`.

## Возможности веб-версии

- **Главная.** Количество слов, завершённых тренировок и дней активности, столбчатый график действий за семь дней с динамической шкалой и три последних события.
- **Словарь.** Поиск по слову и переводу, добавление и удаление записей. Изменения попадают в историю.
- **Практика.** Три уровня на 5, 10 или 15 вопросов. Для запуска нужны достаточное количество слов и минимум четыре разных перевода. Приложение случайно выбирает слова без повторений, показывает четыре варианта ответа, подсвечивает ответ и обновляет прогресс. Итог сохраняется в истории один раз, в том числе при обновлении страницы результата.
- **История.** Дата и время, действие, описание и общее количество событий. Новые записи отображаются первыми.

Настольная и веб-версии хранят собственные словари и историю в SQLite и PostgreSQL соответственно.

## Краткая справка о настольной версии

После запуска приложения откроется главное окно с боковой панелью навигации.

Для добавления нового слова перейдите в раздел «Словарь», заполните поля и нажмите кнопку «Добавить слово».

Для удаления записи выберите строку в таблице и нажмите «Удалить слово».

Для проверки знаний откройте раздел «Практика», начните тренировку и выбирайте правильные переводы предложенных слов.

Результаты завершённых тренировок и действия со словарём автоматически регистрируются в разделе «История».

Для завершения работы используйте пункт меню «Файл → Выход» или сочетание клавиш Ctrl+Q.

## Структура проекта

- `main.py` — запуск приложения, главное окно, навигация и меню.
- `app/database.py` — инициализация SQLite и репозитории словаря и истории.
- `app/services.py` — проверка данных словаря, журнал активности и подготовка вопросов.
- `app/exceptions.py` — исключение проверки данных словаря.
- `app/ui/` — четыре страницы, общие элементы интерфейса в `widgets.py` и оформление в `styles.qss`.
- `web/main.py` — маршруты FastAPI.
- `web/database.py` — работа со словарём, историей и тренировками в PostgreSQL.
- `web/templates/` и `web/static/` — шаблоны Jinja2 и стили.
- `compose.yaml` — PostgreSQL 17 и постоянный том.
- `tests/` — проверки настольной версии и веб-маршрутов.

## Хранение данных

Файл `app.db` создаётся в корне проекта. SQLite хранит словарь, историю действий и результаты тренировок между запусками. Приложение добавляет восемь начальных слов при создании таблицы словаря. При пустой истории на главной странице отображается демонстрационный график.

## Проверка

Запустите тесты из корня проекта.

```bash
python -m pytest -v
```

Тесты настольной версии используют временную SQLite-базу. Тесты веб-маршрутов подменяют доступ к PostgreSQL, поэтому для этого запуска достаточно установленного Python-окружения.
